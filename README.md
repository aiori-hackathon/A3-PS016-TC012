## Project Overview

This repository contains the proposal, research, and development resources for our AIORI-3 Hackathon project.

The project focuses on benchmarking a conventional A3-RSRP handover algorithm against a supervised Random Forest model using the ns-3 LTE simulator.

Our objective is to evaluate handover reliability and network performance across different mobility speeds through reproducible simulation experiments.

## Project Objectives

- Configure three LTE cells and two mobility speeds.
- Implement the conventional A3-RSRP baseline.
- Develop a supervised Random Forest handover policy.
- Evaluate both policies using multiple random seeds.
- Measure handover failures, ping-pong events, interruption duration, and throughput.
- Generate comparative performance visualizations.

## Dataset Strategy

The primary training dataset will be generated through controlled ns-3 LTE simulations.

Compatible open-source LTE measurement datasets may also be investigated to supplement training and analyze real-world mobility conditions.

## Expected Outcomes

- Reproducible cellular simulation scenarios
- Signal-based handover baseline
- Supervised learning-based handover model
- Multi-seed performance evaluation
- Comparative graphs and technical analysis
- Final technical report and demonstration
